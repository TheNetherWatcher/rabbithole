• Limit order book. The exchange's list of resting buy (bid) and sell (ask) orders at each price. Feeds send Add/Modify/Delete messages. Gross 2024 slides
  • Market data over UDP multicast. Exchanges broadcast binary messages (e.g. Nasdaq ITCH, CME MDP3, which is SBE-encoded). Orders go back over TCP (OUCH, FIX, iLink).
  • CPU memory hierarchy. L1 ≈ 4 cycles, L2 ≈ 12, L3 ≈ 40–50, DRAM ≈ 60–100 ns. Data moves in 64-byte cache lines. 7-cpu Skylake, Drepper
  • Branch prediction. The CPU guesses which way an if goes and runs ahead. A wrong guess costs ≈16–20 cycles on Skylake. 7-cpu
  • Kernel vs user space. A normal socket recv() crosses into the kernel. Kernel-bypass NICs let user code read the NIC's receive ring directly. Kernel timestamping doc
  • Percentiles. p99 = the latency that 99% of events beat. HFT cares about p99.9 and max during bursts, not the mean. Gil Tene

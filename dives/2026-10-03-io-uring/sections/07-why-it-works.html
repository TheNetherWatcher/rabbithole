Core insight: turn syscall into data. A syscall = control transfer + argument marshalling. Move marshalling to shared memory (SQE), make control transfer batched or removable (SQPOLL), and make completion a memory read (CQE).

Ablate each piece:

  • Remove shared rings → back to aio's copies/≥2 syscalls.
  • Remove inline-first attempt → every op pays a context switch to a worker even on page-cache hit (the thread-pool problem).
  • Remove poll-arm path → sockets need a worker thread per blocked op (thousands of threads) or you are back to epoll+read.
  • Remove io-wq fallback → buffered file I/O blocks io_uring_enter (submit stalls for disk), breaking the "submit never blocks" promise.
  • Remove registration → per-op atomic refcount + page pin; Jasny: registered buffers are part of the 2× gain.
  • Remove DEFER_TASKRUN → IPIs interrupt the app mid-batch, break batching, add jitter.
  • Remove the user_data indirection → can't match out-of-order completions.

“0-RTT lets a returning client send its request in the first packet, so you save a round trip.”
  1. It saves exactly one round trip, not “zero”. A TLS 1.3 resumption is already 1-RTT; 0-RTT removes that one. Over TCP the TCP handshake is a separate round trip.
  2. The data is replayable. No fresh server randomness goes into its key, so a network attacker can resend the flight and every check passes.
  3. It is not forward secret. The early key comes from the PSK alone; whoever later gets the ticket-encryption key can decrypt recorded early data.
  4. The server may refuse, silently. It can skip the early data and complete a normal handshake. The client must be ready to resend.
  5. Defenses need state, and fleets rarely share it. The RFC’s minimum is “at most once per server instance”, which is not the same as once.

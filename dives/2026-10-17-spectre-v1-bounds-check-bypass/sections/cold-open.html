A branch predictor guesses which way an if will go, before it knows the answer.

It's right about 95% of the time, which is exactly why it's dangerous: an attacker who controls what you feed it can make it wrong on purpose, on command, and the CPU will run ahead anyway — reading memory it was never allowed to touch.

256 possible cache lines, all cold. The CPU speculatively reads a secret byte and uses it as an index into one of them.
One line is warm. The CPU "undoes" the whole detour — registers, memory, flags — but the warm line stays. Timing all 256 finds it instantly.

• Offered load λ vs capacity μ: requests/s arriving vs requests/s the server can finish. Utilisation ρ = λ/μ. (Brooker, "Latency sneaks up on you")
  • Queueing delay explodes near ρ → 1: for M/M/1, mean number in system = ρ/(1−ρ): 1 at ρ=0.5, 99 at ρ=0.99.
  • Little's law: N = λW. Concurrency equals arrival rate times time in system, so latency up means more in flight.
  • Goodput ≠ throughput: goodput counts only work that finished in time for someone to use it. (Amazon Builders' Library, load shedding)
  • Open vs closed system: in an open system, new requests keep arriving regardless of how slow you are (internet traffic). In a closed system, a fixed set of clients waits for each reply before sending the next (most benchmarks). (Schroeder et al., NSDI'06)
  • Timeout + retry: the client gives up after T and sends another attempt. The server usually never finds out about the first one.

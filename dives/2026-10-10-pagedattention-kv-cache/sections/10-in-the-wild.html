• vLLM V1. Block 16. gpu_memory_utilization is 0.92 in code (older docs say 0.9). Prefix caching on with hash chains and LRU that evicts the tail block first. Recompute preemption, chunked prefill on with decodes first, append-only block tables. Deviates from the paper, which defaulted to swap and pre-reserved shared prefixes explicitly.
  • TensorRT-LLM. 128 tokens per block, fixed at build. Reuse on by default, but blocks become reusable only after the producing request terminates. Host secondary cache.
  • TGI. vLLM kernels plus a block table; prefix-cache policy not documented (unverified).
  • SGLang. Radix-tree reuse. Up to 6.4× throughput, but that's the whole runtime, not RadixAttention alone. Page-size default unverified.
  • Mooncake / LMCache / CachedAttention. Blocks move across HBM, DRAM, SSD and machines. Mooncake: up to 525% (simulated), +75% requests in production.

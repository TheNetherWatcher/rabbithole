OS paging. Request = process. Token = byte. KV block = page. Block table = page table. Free pool = frame allocator. Parallel samples = fork() with copy-on-write. Preemption = swap-out.

Where it breaks. (1) No MMU or TLB: the kernel loads block_table[j] and computes addresses itself. (2) Every step reads every block, so there's no working set and you evict whole sequences, all or nothing. (3) KV can be recomputed instead of swapped (vLLM V1's default). (4) Blocks are append-only, so the last block is the only fragmentation.

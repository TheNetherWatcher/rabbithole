A hash table lookup should cost about one memory access.

Swiss tables check 16 slots at once by keeping a 1-byte fingerprint per slot and comparing them all in a single CPU instruction. The fingerprint is only 7 bits, so it can be wrong.

One group, 16 tags, one compare. Filled = occupied slot, bright = tag matches.
About 1 slot in 128 matches by chance, so at 7/8 load a group visit costs ≈0.11 wasted key compares (14 occupied ÷ 128).

A Map is a struct definition discovered at runtime. An object is a struct instance: a map*, a properties*, an elements*, then the in-object fields. An IC is a JIT-style switch (map) at each site.

Where the analogy breaks: C structs are fixed at compile time. Maps are discovered as the program runs, can mutate (field generalization, deprecation), and can be abandoned for dictionary mode. And the "switch" can be baked into machine code, which makes invalidation a first-class problem.

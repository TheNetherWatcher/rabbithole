• Term / AST: a tree like (/ (* a 2) 2). Rewrites turn one term into an equal one. (egg tutorial)
  • Union-find: a forest that answers "are x and y in the same set?" in near-constant amortized time; find returns the set's canonical representative, union links two roots. (Wikipedia)
  • Hash-consing: never build the same node twice; a hash map from node → id gives structural sharing (a DAG instead of a tree).
  • Congruence: if a ≡ b then f(a) ≡ f(b). The "closure" is everything you can derive this way. (Nelson & Oppen 1980)
  • Phase ordering: an optimizer's passes destroy information, so the order you run them in changes the output. That's the problem e-graphs attack.
  • Datalog / conjunctive query: rules over relations joined on shared variables; relevant because modern e-matching is a database join. (relational e-matching)

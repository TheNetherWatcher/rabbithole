• Collapse loop: a popular expert gets more gradient, which makes it better, which makes it more popular.
  • Aux-loss dilemma (§6): too small and the router collapses, too large and specialization is erased.
  • Micro-batch balancing bug (Qiu et al. 2025): frameworks compute the load-balance loss per micro-batch of 1–4 sequences, which forces within-sequence uniformity. That punishes a code-only sequence for using the code experts. Global-batch balance loss fixes it.
  • Stragglers: EP all-to-all is a synchronous barrier, so one hot GPU stalls all of them.
  • Inference: there is no controller at serve time, so routing depends on batch composition.
  • Security: cross-batch dependencies leak. Hayes, Shumailov and Yona (2024, Buffer Overflow in Mixture of Experts) show that token dropping under capacity limits lets an attacker’s co-batched queries alter a victim’s output. Figure 1 shows the flow. Figure 3 shows the attack in numbers: the victim’s tokens fall from 6 to 0 as adversarial tokens fill the expert’s 20-slot buffer.

Yona, Shumailov, Hayes and Carlini (2024, Stealing User Prompts) exploit Expert-Choice routing plus CUDA topk tie-breaking to recover a victim prompt with about 100 queries per token, shown on a two-layer Mixtral.

  • Misconception: “experts specialise in domains”. Wang, Hayou and Nalisnick (2026) argue that routing reflects the geometry of the hidden space. Mixtral’s own analysis found syntactic, token-level rather than topical specialization.

Imagine a warehouse that has to throw away anything nobody can reach anymore, but it can't close while it counts. So an inspector walks the aisles with tags: white means "haven't seen this box yet", grey means "seen it, haven't looked inside", black means "seen it and everything it points to". When the walk ends, every box still tagged white gets thrown out.

The trouble is that clerks keep moving boxes while the inspector works. A clerk can lift a white box off a shelf the inspector is about to skip, hold it, and clear the shelf. The inspector then finishes the walk, never sees that box, and bins it while the clerk is still carrying it. Go's garbage collector has this exact problem, and the fix is a house rule: whenever a clerk takes a box off a shelf or puts one onto a shelf, they call out its name and the inspector tags it. The clerk's own hands and pockets are too busy to police, so the inspector checks them once. The clever part of Go's rule is that after that one check, the pockets never need checking again.

Everyday example

Priya is a clerk. Shelf B holds box C. The inspector has already checked Priya's pockets (empty) and has just tagged shelf B as "to look inside". Priya takes C from shelf B into her hands, then clears the slot on the shelf. She calls out "C" as she clears the slot, so the inspector tags it. The inspector looks inside shelf B (now empty) and moves on, but C is already tagged and is kept. Without the call-out, C would still be white at the end, and the box in Priya's hands would be binned.

Before Go 1.8 the call-out rule was weaker, so the inspector had to close the shop at the end and re-check every clerk's pockets one last time. With 100,000 clerks that took long enough for customers to notice. The new rule removes the re-check.

• Tracing GC: an object is live if a chain of pointers leads to it from a root (goroutine stacks, globals, registers). Everything else is freed. Go GC guide.
  • Concurrent marking: the collector traces while the program (the mutator) keeps running and rewiring pointers, so the graph changes under the tracer.
  • Tri-color abstraction: white = unvisited, grey = visited but its pointers not yet scanned (on the work queue), black = visited and scanned. White objects left at the end are garbage.
  • Strong invariant: no black object points to a white object. If it holds, finishing the grey queue marks everything reachable. Design doc 17503.
  • Write barrier: a few instructions the compiler wraps around pointer stores into the heap, so the collector hears about the change. Stack writes get none, because they are far too frequent.
  • Stop-the-world (STW): every goroutine pauses. Go keeps two short STW phases per cycle (sweep termination and mark termination).
